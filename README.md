# Internet speed test

Небольшой скрипт для примерной оценки скорости скачивания с указанного адреса.
Он последовательно выполняет 10 запросов, считает среднее время ответа, общий
объём данных и среднюю скорость в Мбит/с.

## Требования

- Python 3.9 или новее
- сторонние библиотеки не нужны

## Запуск

```bash
python speed_test.py "https://example.com/large-image.jpg"
```

При необходимости можно изменить тайм-аут одного запроса:

```bash
python speed_test.py "https://example.com/large-image.jpg" --timeout 60
```

Лучше использовать прямую ссылку на достаточно большой файл. На маленьком
файле результат будет неточным, потому что заметную часть времени займут
установка соединения и задержка сервера.

## Как считается скорость

Скрипт складывает объём данных, полученных во всех десяти запросах, переводит
его в биты и делит на суммарное время скачивания. Для вывода в Мбит/с результат
делится на 1 000 000.

Запросы выполняются последовательно, как указано в задании. Полученный результат
зависит не только от интернет-соединения, но и от скорости выбранного сервера.
